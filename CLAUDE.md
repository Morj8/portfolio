# CLAUDE.md

## Project
Single-page personal portfolio for Morag Gil (Business Applications & AI Automation Manager), in English.
Plain HTML + CSS only: no frameworks, no build tools, no npm.

## Content rules
- Real facts only, taken from Morag's LinkedIn profile. Never invent roles, numbers, projects or skills.
- Write the company name as "CYBR".
- No phone number, email or home address on the page.

## File structure
- `index.html` – the page (header, main with About / What I do / Experience sections, footer)
- `style.css` – basic styles (one font, max-width container, mobile layout)
- `images/profile.jpg` – profile photo
- `README.md` – short description of the project
- `.gitignore` – keeps `portfolio-prompt.md` and `Profile.pdf` out of the public repo
